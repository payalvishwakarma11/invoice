# 🚕 Taxi Invoice Generator

This project is a simple and practical web application that I built to solve a real problem — generating taxi bills quickly.

Many small taxi drivers don’t have proper billing systems. So I created this tool where anyone can enter trip details and instantly generate a professional invoice with just one click.

---

## 🌐 Live Project

You can try it here:
👉 https://payalvishwakarma11.github.io/invoice/

---

## 💡 What this project does

* Takes customer and trip details
* Automatically calculates total fare
* Generates a clean taxi invoice
* Allows users to download it as a PDF
* Provides print option for offline use

---

## ✨ Features I implemented

* Simple and user-friendly interface
* Real-time fare calculation
* One-click invoice generation
* PDF download using JavaScript
* Mobile-friendly design
* WhatsApp sharing option
* UPI QR support for payments

---

## 🛠️ Technologies used

* HTML for structure
* CSS for styling
* JavaScript for logic and functionality
* html2pdf.js for PDF generation

---

## 🚀 How to use

1. Fill in customer details
2. Enter trip information
3. Click on "Generate Invoice"
4. Download or print the bill

---

## 🎯 Why I built this

I wanted to create something useful in real life, not just a theory-based project.
This project can actually be used by taxi drivers for daily billing.
